# Temperature Converter

Небольшая консольная программа на Rust для перевода температуры между градусами Цельсия и Фаренгейта.

Проект создан в процессе изучения языка Rust и практики работы с условными конструкциями, переменными и пользовательским вводом.

## Возможности

- Перевод градусов Цельсия в градусы Фаренгейта.
- Перевод градусов Фаренгейта в градусы Цельсия.
- Ввод температуры через консоль.
- Выбор направления конвертации с помощью меню.

## Формулы

**Цельсий → Фаренгейт**

°F = °C × 1.8 + 32

**Фаренгейт → Цельсий**

°C = (°F − 32) × 5 / 9

## Пример работы

```text
1. Перевести градусы Цельсия в Фаренгейт
2. Перевести градусы Фаренгейта в Цельсий
1
Введите температуру:
25
77
```

Другой пример:

```text
1. Перевести градусы Цельсия в Фаренгейт
2. Перевести градусы Фаренгейта в Цельсий
2
Введите температуру:
98.6
37.00
```
